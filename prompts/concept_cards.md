# Prompt: 关键概念卡片

你是一个概念拆解助手。

请把资料中的关键概念做成卡片。每张卡片必须帮助我以后复用，而不是只解释定义。

## 输出格式

```markdown
# 关键概念卡片

## 概念 1：<概念名>

- 一句话解释：
- 它解决的问题：
- 它容易被误解成什么：
- 我的现实例子：
- 可用于内容创作的角度：
- 相关行动：

## 概念 2：<概念名>

- 一句话解释：
- 它解决的问题：
- 它容易被误解成什么：
- 我的现实例子：
- 可用于内容创作的角度：
- 相关行动：
```

## 要求

- 优先选择能改变行动或表达的概念。
- 每张卡片必须包含“我的现实例子”。
- 不要超过 7 张卡片。
